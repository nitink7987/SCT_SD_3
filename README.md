# Sudoku Solver

A browser-based Sudoku solver using a backtracking algorithm. It loads the sample puzzle from the Python code. Edit empty cells to enter another puzzle, then select **Solve puzzle**.

## Files

- `index.html` — page structure
- `style.css` — grid and page styling
- `script.js` — puzzle validation and solving logic

## Run locally

Keep all three files in the same folder and open `index.html` in a web browser. No installation or server is required.

Enter digits 1–9 in empty cells and leave unknown cells blank. Select **Reset** to restore the original sample puzzle.
